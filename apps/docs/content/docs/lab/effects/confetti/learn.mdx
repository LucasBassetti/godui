  code={`const DEFAULTS: ConfettiOptions = {
  spread: 70,
  startVelocity: 45,
  particleCount: 120,
  origin: { y: 0.7 },
  disableForReducedMotion: true,
};`}
>

`Confetti` is a thin wrapper. It leaves particle physics to `canvas-confetti`
and adds shared defaults, three call sites, and one accessibility flag that the
library already understands.

Every fire path merges the same base options. Spread, velocity, count, and a
default origin height are tuned once; call sites only override what they need.

`origin.y: 0.7` parks bursts in the lower third of the viewport when no
explicit origin is passed, so the burst rises from below instead of falling
from the top of the screen.

</LearnChapter>

<LearnChapter
  label="ConfettiButton: rect → viewport fractions"
  scene={<ConfettiOrigin />}
  code={`const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
  const rect = e.currentTarget.getBoundingClientRect();
  const x = (rect.left + rect.width / 2) / window.innerWidth;
  const y = (rect.top + rect.height / 2) / window.innerHeight;
  canvasConfetti({ ...DEFAULTS, origin: { x, y }, ...options });
  onClick?.(e);
};`}
>

The button has no hard-coded origin. On click it measures itself, normalizes
its center into `0…1` viewport space, and passes that as `origin: { x, y }`.
The burst comes from the control wherever it sits after layout, scroll, or
resize.

`options` are merged last. You can widen the spread or bump the count and keep
the positional origin, unless you override `origin` too.

</LearnChapter>

<LearnChapter
  label="Three APIs, one core"
  scene={<ConfettiApi />}
  code={`React.useImperativeHandle(
  ref,
  () => ({
    fire: (override?: ConfettiOptions) => {
      canvasConfetti({ ...DEFAULTS, ...options, ...override });
    },
  }),
  [options],
);

function confetti(options?: ConfettiOptions) {
  canvasConfetti({ ...DEFAULTS, ...options });
}`}
>

Same merge, three ergonomics:

1. **`ConfettiButton`**: declarative trigger, origin from the click target.
2. **`<Confetti ref />` + `fire()`**: imperative, toast-style; returns
   `null` (no DOM).
3. **`confetti(options?)`**: bare helper for non-React call sites.

</LearnChapter>

## Reduced motion

`disableForReducedMotion: true` is in `DEFAULTS`, so every path opts in.
`canvas-confetti` suppresses the burst when the user prefers reduced motion,
so GodUI needs no `useReducedMotion` branch of its own.
