**GodUI** is shadcn/ui, animated. Every component is a drop-in replacement for
its [shadcn/ui](https://ui.shadcn.com) counterpart: the same file, the same
exports and props, the same Radix primitives, so you can install it over a
component you already use and every call site keeps working. What changes is
the motion.

## What you get

- **A drop-in for shadcn/ui.** `npx shadcn add @godui/dialog` overwrites
  `components/ui/dialog.tsx`. Imports, props and `data-slot`s don't change.
- **GPU-only motion.** Every animation moves only `transform`, `opacity` or
  `filter`, so it runs on the compositor and stays smooth under load. A lint
  and a Chrome trace test enforce it in CI.
- **Springs in plain CSS.** Enter animations use spring curves written as CSS
  `linear()`. There's no animation runtime to ship.
- **Reduced motion built in.** Under `prefers-reduced-motion`, movement turns
  into short fades.
- **You own the code.** Components are copied into your project by the shadcn
  CLI. There's no versioned dependency to upgrade.

Looking for the effects, backgrounds and showpieces from GodUI v1? They live in
[Extras](/docs/extras).
