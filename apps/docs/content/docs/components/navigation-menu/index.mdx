## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@/components/ui/navigation-menu";
```

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Item One</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink>Link</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

## API

### NavigationMenu

Built on [Radix Navigation Menu Root](https://www.radix-ui.com/primitives/docs/components/navigation-menu#root); renders a `<nav>` and accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `viewport` | `boolean` | `true` | Render the shared `NavigationMenuViewport`. With `false`, each content opens under its own trigger. |
| `value` | `string` | none | Controlled value of the open item. Empty string when none is open. |
| `defaultValue` | `string` | none | Initially open item when uncontrolled. |
| `onValueChange` | `(value: string) => void` | none | Called when the open item changes. |
| `delayDuration` | `number` | `200` | Milliseconds of hover before a trigger opens. |
| `skipDelayDuration` | `number` | `300` | Window in ms after leaving a trigger during which the next one opens without delay. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout of the list, used for keyboard navigation. |
| `dir` | `"ltr" \| "rtl"` | none | Reading direction. Inherits from `DirectionProvider` when unset. |

### NavigationMenuList

Built on [Radix Navigation Menu List](https://www.radix-ui.com/primitives/docs/components/navigation-menu#list); renders a `<ul>` and accepts all its props.

### NavigationMenuItem

Built on [Radix Navigation Menu Item](https://www.radix-ui.com/primitives/docs/components/navigation-menu#item); renders a `<li>` and accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Identifies the item for the menu's `value`. Generated when unset. |

### NavigationMenuTrigger

Built on [Radix Navigation Menu Trigger](https://www.radix-ui.com/primitives/docs/components/navigation-menu#trigger); renders a `<button>` with a chevron after its children and accepts all its props. A click on a trigger that hover just opened keeps it open.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | none | Prevents the item from opening. |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### NavigationMenuContent

Built on [Radix Navigation Menu Content](https://www.radix-ui.com/primitives/docs/components/navigation-menu#content); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `forceMount` | `true` | none | Keep the content mounted while closed. |
| `onEscapeKeyDown` | `(event: KeyboardEvent) => void` | none | Called on Escape. `event.preventDefault()` keeps it open. |
| `onPointerDownOutside` | `(event: PointerDownOutsideEvent) => void` | none | Called on a press outside. `event.preventDefault()` keeps it open. |

### NavigationMenuLink

Built on [Radix Navigation Menu Link](https://www.radix-ui.com/primitives/docs/components/navigation-menu#link); renders an `<a>` and accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` | none | Marks the link as the current page (`data-active`, `aria-current="page"`). |
| `onSelect` | `(event: Event) => void` | none | Called when the link is chosen. `event.preventDefault()` keeps the menu open. |
| `asChild` | `boolean` | `false` | Render the child element instead, e.g. a framework `Link`. |

### NavigationMenuViewport

Built on [Radix Navigation Menu Viewport](https://www.radix-ui.com/primitives/docs/components/navigation-menu#viewport); accepts all its props. `NavigationMenu` renders it for you unless `viewport={false}`. It sits centered under the open trigger, kept inside the menu, and holds an inert copy of the content you leave until its exit animation ends.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `forceMount` | `true` | none | Keep the viewport mounted while closed. |

### NavigationMenuIndicator

Built on [Radix Navigation Menu Indicator](https://www.radix-ui.com/primitives/docs/components/navigation-menu#indicator); accepts all its props. Radix positions it from the trigger's `offsetLeft`, so give the items `className="static"` for it to move.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `forceMount` | `true` | none | Keep the indicator mounted while hidden. |

### navigationMenuTriggerStyle

The `cva` function behind `NavigationMenuTrigger`. Call `navigationMenuTriggerStyle()` to style a `NavigationMenuLink` as a trigger. It works in Server Components.

Props match [shadcn/ui Navigation Menu](https://ui.shadcn.com/docs/components/navigation-menu).
