## Usage

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip";
```

Wrap your app (or the area using tooltips) in `TooltipProvider` once, as with
shadcn/ui.

```tsx
<Tooltip>
  <TooltipTrigger>Hover</TooltipTrigger>
  <TooltipContent>
    <p>Add to library</p>
  </TooltipContent>
</Tooltip>
```

## API

### TooltipProvider

Built on [Radix Tooltip Provider](https://www.radix-ui.com/primitives/docs/components/tooltip#provider); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delayDuration` | `number` | `0` | Milliseconds from pointer enter until a tooltip opens. Radix defaults to 700. |
| `skipDelayDuration` | `number` | `300` | Milliseconds after a tooltip closes during which the next trigger opens it instantly. |
| `disableHoverableContent` | `boolean` | `false` | Close as soon as the pointer leaves the trigger, even when moving onto the content. |

### Tooltip

Built on [Radix Tooltip Root](https://www.radix-ui.com/primitives/docs/components/tooltip#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | none | Controlled open state. |
| `defaultOpen` | `boolean` | none | Open state on first render when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the open state changes. |
| `delayDuration` | `number` | provider's value | Overrides the provider's `delayDuration` for this tooltip. |
| `disableHoverableContent` | `boolean` | provider's value | Overrides the provider's `disableHoverableContent` for this tooltip. |

### TooltipTrigger

Built on [Radix Tooltip Trigger](https://www.radix-ui.com/primitives/docs/components/tooltip#trigger); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element (e.g. a `Button`) as the trigger instead of a `<button>`. |

### TooltipContent

Built on [Radix Tooltip Content](https://www.radix-ui.com/primitives/docs/components/tooltip#content); accepts all its props. Renders inside a portal with an arrow.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"top"` | Preferred side of the trigger. Also sets the direction of the entrance drift. |
| `sideOffset` | `number` | `0` | Distance in pixels from the trigger. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `alignOffset` | `number` | `0` | Offset in pixels from the `align` position. |
| `avoidCollisions` | `boolean` | `true` | Flip or shift to stay inside the collision boundary. |
| `collisionPadding` | `number \| Partial<Record<Side, number>>` | `0` | Distance in pixels from the boundary edges where collisions are detected. |
| `forceMount` | `true` | none | Keep the content mounted while closed. |

Props match [shadcn/ui Tooltip](https://ui.shadcn.com/docs/components/tooltip).
