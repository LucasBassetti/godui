The shadcn/ui input group. Focus the field and the ring fades in while it
grows from 99% to full size, then sits exactly where shadcn's ring sits. The
ring is a `::before` layer, so only its `opacity` and `scale` change; the
border colour snaps. Addon buttons stay clickable through it.

## Replacing shadcn

`npx shadcn add @godui/input-group` overwrites `components/ui/input-group.tsx`
(and installs GodUI's `button`, `input` and `textarea`). Exports, props and
`data-slot` attributes match shadcn/ui new-york-v4, so existing imports keep
working. It also installs `godui-motion` for the easing and duration tokens.

The group's focus and invalid ring classes move to its `::before`
(`before:ring-[3px]` instead of `ring-[3px]`). If a call site set a ring
colour on the group, prefix it with `before:`. Don't put `overflow-hidden` on
the group: the ring sits outside its border, like shadcn's. The layer reaches
that border box with `before:-inset-px`, which assumes shadcn's 1px `border`;
if you give the group a thicker one, match it (`border-2` with
`before:-inset-0.5`), or the ring starts inside the border.

## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group";
```

```tsx
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## What's animated

Turn on Slow motion in the Focus ring example to watch the ring grow on a 900ms clock.

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Focus ring | `::before` transition | `opacity`, `scale` | `ease-out-expo` | 150ms |
| Border colour, invalid colour | snap | — | — | — |

Blur fades it out the same way. The ring is shadcn's: 3px of
`ring/50` (or `destructive/20`, `destructive/40` in dark, on an invalid
control), drawn by a layer that covers the group's border box with the same
radius.

Under `prefers-reduced-motion` the ring appears and disappears without a
transition.

## API

Props are identical to [shadcn/ui Input Group](https://ui.shadcn.com/docs/components/input-group).

| Component | Props |
| --- | --- |
| `InputGroup` | `div` props |
| `InputGroupAddon` | `align`: `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` (default `"inline-start"`) |
| `InputGroupButton` | `Button` props; `size`: `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` (default `"xs"`), `variant` (default `"ghost"`) |
| `InputGroupText` | `span` props |
| `InputGroupInput` | `input` props |
| `InputGroupTextarea` | `textarea` props |
