## API

### Slider

Built on [Radix Slider Root](https://www.radix-ui.com/primitives/docs/components/slider#root); accepts all its props. Renders the track, range and one thumb per value.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `number[]` | none | Initial values when uncontrolled. One thumb per entry. |
| `value` | `number[]` | none | Controlled values. A new value glides the thumb there. |
| `onValueChange` | `(value: number[]) => void` | none | Called on every value change, including while dragging. |
| `onValueCommit` | `(value: number[]) => void` | none | Called when the user ends an interaction (pointer up, key press). |
| `min` | `number` | `0` | Minimum value. |
| `max` | `number` | `100` | Maximum value. |
| `step` | `number` | `1` | Stepping interval. |
| `minStepsBetweenThumbs` | `number` | `0` | Minimum number of steps between thumbs in a range. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout axis. Vertical sliders take the parent's height (min 11rem). |
| `inverted` | `boolean` | `false` | Flip the direction the value increases. |
| `disabled` | `boolean` | `false` | Prevent interaction. |
| `name` | `string` | none | Form field name for the hidden inputs. |
