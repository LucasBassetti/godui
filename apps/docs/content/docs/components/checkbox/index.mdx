## API

### Checkbox

Built on [Radix Checkbox Root](https://www.radix-ui.com/primitives/docs/components/checkbox#root); accepts all its props. Renders a `<button role="checkbox">` with the check mark inside.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean \| "indeterminate"` | none | Controlled checked state. |
| `defaultChecked` | `boolean \| "indeterminate"` | `false` | Checked state on first render, when uncontrolled. |
| `onCheckedChange` | `(checked: boolean \| "indeterminate") => void` | none | Called when the checked state changes. |
| `disabled` | `boolean` | `false` | Prevents interaction. |
| `required` | `boolean` | `false` | Marks the checkbox as required in a form. |
| `name` | `string` | none | Field name submitted with a form. |
| `value` | `string` | `"on"` | Value submitted with a form when checked. |

Props match [shadcn/ui Checkbox](https://ui.shadcn.com/docs/components/checkbox).
