the check mark is drawn in from left to right. Both run only when the state
changes, so a form that loads with boxes already checked doesn't animate.
Only `scale`, `translate` and `opacity` animate.

## Replacing shadcn

`npx shadcn add @godui/checkbox` overwrites `components/ui/checkbox.tsx`.
Exports, props and `data-slot` attributes match shadcn/ui new-york-v4, so
existing imports keep working. It also installs `godui-motion` (easings,
keyframes, the FLIP hook) into your project.

## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Check (box) | `godui-pop` | `scale` 1 → 0.85 → 1 | `ease-spring-bouncy` | 260ms |
| Check (mark) | `godui-slide-in-from-left` inside a clipped indicator | `translate`, `opacity` | `ease-spring-smooth` | 260ms |
| Uncheck, fill, border | snap | — | — | — |

Animations run only after the checked state changes, by a click, the keyboard
or a controlled `checked` prop, never on the first render.

Under `prefers-reduced-motion` the box doesn't dip and the check fades in
without sliding.
