when the box is checked, and the box itself presses down on a spring while
the pointer is on it. The fill and border change instantly. Only `scale` and

## Replacing shadcn

`npx shadcn add @godui/checkbox` overwrites `components/ui/checkbox.tsx`.
Exports, props and `data-slot` attributes match shadcn/ui new-york-v4, so
existing imports keep working. It also installs `godui-motion` (easings,
keyframes, the FLIP hook) into your project.

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox";
```

```tsx
<Checkbox />
```

## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Check | `godui-fade-scale-in` from 50% | `scale`, `opacity` | `ease-spring-snappy` | 260ms |
| Press | `transition` on `active:scale-[0.92]` | `scale` | `ease-spring-bouncy` | 260ms |
| Fill, border | snaps | — | — | — |

Unchecking has no exit animation: the fill clears immediately, and a white
check shrinking on an empty box would be invisible.

Under `prefers-reduced-motion` the check fades in without scaling and the box
presses instantly.

Built on [Radix Checkbox](https://www.radix-ui.com/primitives/docs/components/checkbox).
Props are identical to [shadcn/ui Checkbox](https://ui.shadcn.com/docs/components/checkbox).
