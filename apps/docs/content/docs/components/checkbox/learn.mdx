Drawing a check stroke by stroke would mean animating `stroke-dashoffset`,
which repaints the SVG on every frame. GodUI fakes it with a clip instead.

The indicator is `overflow-hidden`, and the check inside it starts one full
width to the left (`--godui-enter-distance: 100%`) and slides into place.
Because the indicator clips it, you see the mark revealed left to right, the
direction a check is drawn, while only `translate` moves. The keyframe sits on
a `<span>` around the icon, because Chrome won't composite `translate` on an
`<svg>` itself.

</LearnChapter>

@keyframes godui-pop {
  40% { scale: calc(1 - (1 - var(--godui-pop-scale)) * var(--godui-motion)); }
}`}
>

At the same moment, the box itself dips to 85% and springs back on
`ease-spring-bouncy`. The shared `godui-pop` keyframe has a single 40% frame,
so the box squashes and returns past its size with the spring's overshoot.

The fill and border change instantly. On a 16px box, the dip and the drawn
check already say "checked"; a color tween would only add paint work.

</LearnChapter>

<LearnChapter
  label="Never on page load"
  scene={<AutoPlayScene label="Never on page load" demo="checkbox" />}
  code={`const [animate, setAnimate] = React.useState(false);
const [lastChecked, setLastChecked] = React.useState(checked);
if (checked !== lastChecked) {
  setLastChecked(checked);
  setAnimate(true);
}

<CheckboxPrimitive.Root
  data-animate={animate || undefined}
  onCheckedChange={(value) => {
    setAnimate(true);
    onCheckedChange?.(value);
  }}
/>`}
>

A settings page that loads with ten boxes already checked shouldn't pop ten
times. So the checkbox only animates after its state actually changes.

It starts with `data-animate` unset, which turns both keyframes off. The first
change sets it: a click or Space through `onCheckedChange`, or a controlled
`checked` prop compared against the last value during render. From then on,
every check pops and draws. The comparison runs during render rather than in
an effect, so the class is already there when the indicator mounts, and the
check never flashes in place before animating.

## Why GPU-only

The box animates `scale`; the check animates `translate` and `opacity` inside a
clip. shadcn's checkbox transitions the focus ring's `box-shadow`; GodUI's
doesn't.

## Reduced motion

`--godui-motion: 0` cancels the dip and the slide, so the check only fades in.
