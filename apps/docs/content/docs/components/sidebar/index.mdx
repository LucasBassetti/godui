## Usage

```tsx
import { SidebarProvider, SidebarTrigger } from "@/components/ui/sidebar";
import { AppSidebar } from "@/components/app-sidebar";

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar />
      <main>
        <SidebarTrigger />
        {children}
      </main>
    </SidebarProvider>
  );
}
```

## API

### SidebarProvider

Renders a native `<div>` wrapper and accepts all of its props. Holds the open state, persists it in the `sidebar_state` cookie and toggles it on <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>B</kbd>. Set `--sidebar-width` and `--sidebar-width-icon` in `style` to change the widths (`16rem` and `3rem`).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultOpen` | `boolean` | `true` | Open state on first render, when uncontrolled. |
| `open` | `boolean` | none | Controlled open state (desktop). |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the desktop open state changes. |

### Sidebar

Renders a native `<div>` and accepts all of its props. Below 768px it renders a GodUI [Sheet](/docs/components/sheet) instead.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"left" \| "right"` | `"left"` | Edge of the page the sidebar sits on. |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` | `floating` draws a rounded card with a shadow; `inset` pairs with `SidebarInset`. |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` | `offcanvas` slides the panel out, `icon` collapses it to an icon rail, `none` never collapses. |

### SidebarTrigger

Renders a GodUI [Button](/docs/components/button) (`ghost`, `icon`) and accepts all its props. Toggles the sidebar after calling your `onClick`.

### SidebarRail

Renders a native `<button>` and accepts all of its props. A thin hit area on the panel's edge that toggles the sidebar.

### SidebarInset

Renders a native `<main>` and accepts all of its props. The page content beside an `inset` sidebar.

### SidebarHeader, SidebarFooter, SidebarContent

Render a native `<div>` and accept all of their props. The header and footer stay put; the content between them scrolls.

### SidebarGroup, SidebarGroupContent

Render a native `<div>` and accept all of their props. A group is a section of the panel.

### SidebarGroupLabel

Renders a native `<div>` and accepts all of its props. Hidden in icon mode.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### SidebarGroupAction

Renders a native `<button>` and accepts all of its props. Sits in the group's top-right corner. Hidden in icon mode.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### SidebarMenu, SidebarMenuItem

Render a native `<ul>` and `<li>` and accept all of their props.

### SidebarMenuButton

Renders a native `<button>` and accepts all of its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead (e.g. a link), merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |
| `isActive` | `boolean` | `false` | Marks the current page; sets `data-active`. |
| `variant` | `"default" \| "outline"` | `"default"` | Visual style. |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` | Height: `h-8`, `h-7` or `h-12`. |
| `tooltip` | `string \| ComponentProps<typeof TooltipContent>` | none | Tooltip shown on hover while collapsed to icons on desktop. |

### SidebarMenuAction

Renders a native `<button>` and accepts all of its props. Sits at the right of a menu item. Hidden in icon mode.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |
| `showOnHover` | `boolean` | `false` | Show the action only while its item is hovered, focused or open (always visible on mobile). |

### SidebarMenuBadge

Renders a native `<div>` and accepts all of its props. A count or label at the right of a menu item. Hidden in icon mode.

### SidebarMenuSkeleton

Renders a native `<div>` and accepts all of its props. A loading placeholder for a menu item, with a random text width between 50% and 90%.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showIcon` | `boolean` | `false` | Adds an icon placeholder before the text. |

### SidebarMenuSub, SidebarMenuSubItem

Render a native `<ul>` and `<li>` and accept all of their props. A nested menu under a menu item. Hidden in icon mode.

### SidebarMenuSubButton

Renders a native `<a>` and accepts all of its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |
| `size` | `"sm" \| "md"` | `"md"` | Text size: `text-xs` or `text-sm`. |
| `isActive` | `boolean` | `false` | Marks the current page; sets `data-active`. |

### SidebarInput, SidebarSeparator

Render a GodUI [Input](/docs/components/input) and Separator, styled for the panel; accept all their props.

### useSidebar

Reads the sidebar state. Must be called inside `SidebarProvider`.

| Field | Type | Description |
| --- | --- | --- |
| `state` | `"expanded" \| "collapsed"` | Desktop state, also set as `data-state` on the sidebar. |
| `open` | `boolean` | Whether the desktop sidebar is open. |
| `setOpen` | `(open: boolean) => void` | Opens or closes the desktop sidebar. |
| `openMobile` | `boolean` | Whether the mobile sheet is open. |
| `setOpenMobile` | `(open: boolean) => void` | Opens or closes the mobile sheet. |
| `isMobile` | `boolean` | `true` below 768px. |
| `toggleSidebar` | `() => void` | Toggles the mobile sheet or the desktop sidebar, whichever is active. |

Props match [shadcn/ui Sidebar](https://ui.shadcn.com/docs/components/sidebar).
