## Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetDescription,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet";
```

```tsx
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

## API

### Sheet

Built on [Radix Dialog Root](https://www.radix-ui.com/primitives/docs/components/dialog#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | none | Controlled open state. |
| `defaultOpen` | `boolean` | none | Open state on first render, when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the sheet opens or closes. |
| `modal` | `boolean` | `true` | When `true`, outside elements can't be interacted with and focus is trapped inside. |

### SheetTrigger, SheetClose

Built on [Radix Dialog Trigger](https://www.radix-ui.com/primitives/docs/components/dialog#trigger) and [Close](https://www.radix-ui.com/primitives/docs/components/dialog#close); accept all their props. The trigger opens the sheet, the close button closes it.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### SheetContent

Built on [Radix Dialog Content](https://www.radix-ui.com/primitives/docs/components/dialog#content); accepts all its props. Renders in a portal with an overlay behind it.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"right"` | Edge the sheet slides in from. |
| `showCloseButton` | `boolean` | `true` | Renders the close (X) button in the top-right corner. |
| `onEscapeKeyDown` | `(event: KeyboardEvent) => void` | none | Called when Escape is pressed. Prevent it to keep the sheet open. |
| `onInteractOutside` | `(event: PointerDownOutsideEvent \| FocusOutsideEvent) => void` | none | Called on a pointer down or focus outside the sheet. Prevent it to keep the sheet open. |
| `onOpenAutoFocus` | `(event: Event) => void` | none | Called when focus moves into the sheet on open. Prevent it to focus something else. |
| `onCloseAutoFocus` | `(event: Event) => void` | none | Called when focus returns to the trigger on close. |
| `forceMount` | `true` | none | Keep the content mounted while closed. |

### SheetHeader, SheetFooter

Render a native `<div>` and accept all of its props. The header stacks the title and description; the footer sits at the bottom of the sheet.

### SheetTitle

Built on [Radix Dialog Title](https://www.radix-ui.com/primitives/docs/components/dialog#title); accepts all its props. Announced as the sheet's accessible name.

### SheetDescription

Built on [Radix Dialog Description](https://www.radix-ui.com/primitives/docs/components/dialog#description); accepts all its props. Announced as the sheet's description.

Props match [shadcn/ui Sheet](https://ui.shadcn.com/docs/components/sheet).
