## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible";
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Can I use this in my project?</CollapsibleTrigger>
  <CollapsibleContent>
    Yes. Free to use for personal and commercial projects. No attribution
    required.
  </CollapsibleContent>
</Collapsible>
```

## API

### Collapsible

Built on [Radix Collapsible Root](https://www.radix-ui.com/primitives/docs/components/collapsible#root); accepts all its props. The root is `relative` so a closing panel has an anchor (with `asChild`, only when the child is otherwise static).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | none | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Open state on first render, when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the panel opens or closes. |
| `disabled` | `boolean` | `false` | Prevents the trigger from toggling. |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### CollapsibleTrigger

Built on [Radix Collapsible Trigger](https://www.radix-ui.com/primitives/docs/components/collapsible#trigger); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, e.g. a GodUI [Button](/docs/components/button). |

### CollapsibleContent

Built on [Radix Collapsible Content](https://www.radix-ui.com/primitives/docs/components/collapsible#content); accepts all its props. Put its content in block elements: loose text directly inside fades instead of sweeping.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element as the panel. Its children hold still while the edge sweeps. |

Props match [shadcn/ui Collapsible](https://ui.shadcn.com/docs/components/collapsible).
