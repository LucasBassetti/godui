```tsx
  <Calendar
    mode="single"

    className="rounded-lg border"
  />
);
```

## API

### Calendar

Built on [React DayPicker](https://daypicker.dev/api/type-aliases/DayPickerProps)'s `DayPicker`; accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `mode` | `"single" \| "multiple" \| "range"` | none | Selection mode. Without it, days can't be selected. |
| `selected` | `Date \| Date[] \| DateRange` | none | Selected day(s). The type follows `mode`. |
| `onSelect` | `(selected, triggerDate, modifiers, e) => void` | none | Called when the selection changes. |
| `required` | `boolean` | `false` | Keep at least one day selected. |
| `month` | `Date` | none | Controlled displayed month. |
| `defaultMonth` | `Date` | current month | Month shown on first render, when uncontrolled. |
| `onMonthChange` | `(month: Date) => void` | none | Called when the displayed month changes. |
| `numberOfMonths` | `number` | `1` | Months shown side by side. |
| `captionLayout` | `"label" \| "dropdown" \| "dropdown-months" \| "dropdown-years"` | `"label"` | Caption as text, or month and year dropdowns. |
| `showOutsideDays` | `boolean` | `true` | Show days from the previous and next month. |
| `fixedWeeks` | `boolean` | `false` | Always show six weeks, so the height never changes. |
| `disabled` | `Matcher \| Matcher[]` | none | Days that can't be selected. |
| `startMonth`, `endMonth` | `Date` | none | First and last month the user can navigate to. |
| `weekStartsOn` | `0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6` | from `locale` | First day of the week (0 is Sunday). |
| `locale` | `Partial<DayPickerLocale>` | `enUS` | date-fns locale for labels and formatting. |
| `min`, `max` | `number` | none | With `multiple` or `range`, the fewest and most days (or nights) allowed. |
| `animate` | `boolean` | `true` | Animate the month change. React DayPicker defaults it to `false`. |
| `buttonVariant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` | [Button](/docs/components/button) variant of the previous and next buttons. |
| `classNames` | `Partial<ClassNames>` | none | Per-part class overrides, merged key by key over GodUI's. |
| `components` | `Partial<CustomComponents>` | none | Replace parts of the calendar, merged over GodUI's `Root`, `Chevron`, `DayButton` and `WeekNumber`. |

### CalendarDayButton

The day cell GodUI passes to DayPicker as `components.DayButton`. Renders a GodUI [Button](/docs/components/button) and accepts DayPicker's `DayButton` props (`day`, `modifiers` and native `<button>` props). Use it to wrap or restyle a day without losing the selection pop, the range track and the range preview.

Props match [shadcn/ui Calendar](https://ui.shadcn.com/docs/components/calendar).
