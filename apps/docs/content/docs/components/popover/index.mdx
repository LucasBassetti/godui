## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@/components/ui/popover";
```

```tsx
<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>Place content for the popover here.</PopoverContent>
</Popover>
```

## API

### Popover

Built on [Radix Popover Root](https://www.radix-ui.com/primitives/docs/components/popover#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | none | Controlled open state. |
| `defaultOpen` | `boolean` | none | Open state on first render, when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the popover opens or closes. |
| `modal` | `boolean` | `false` | When `true`, outside elements can't be interacted with and focus is trapped inside. |

### PopoverTrigger

Built on [Radix Popover Trigger](https://www.radix-ui.com/primitives/docs/components/popover#trigger); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### PopoverAnchor

Built on [Radix Popover Anchor](https://www.radix-ui.com/primitives/docs/components/popover#anchor); accepts all its props. Positions the content against this element instead of the trigger.

### PopoverContent

Built on [Radix Popover Content](https://www.radix-ui.com/primitives/docs/components/popover#content), rendered in a portal; accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side of the trigger. Flips when it would collide. |
| `sideOffset` | `number` | `4` | Distance from the trigger in px. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `alignOffset` | `number` | `0` | Offset from the `align` position in px. |
| `avoidCollisions` | `boolean` | `true` | Flip and shift to stay inside the collision boundary. |
| `collisionPadding` | `number \| Partial<Record<Side, number>>` | `0` | Distance from the boundary edges where collisions are detected. |
| `onOpenAutoFocus` | `(event: Event) => void` | none | Called when focus moves into the content on open. Prevent it to keep focus on the trigger. |
| `onCloseAutoFocus` | `(event: Event) => void` | none | Called when focus returns to the trigger on close. |
| `forceMount` | `true` | none | Keep the content mounted while closed. |

### PopoverHeader, PopoverTitle, PopoverDescription

`PopoverHeader` and `PopoverTitle` render a native `<div>`, `PopoverDescription` a `<p>`; each accepts all of its props. The header stacks the title and description.

Props match [shadcn/ui Popover](https://ui.shadcn.com/docs/components/popover).
