The shadcn/ui wrapper around [Sonner](https://sonner.emilkowal.ski), tuned to
be GPU-only. Sonner moves toasts with `transform` and `opacity`, but it also
transitions `height` (when the stack expands) and `box-shadow`. GodUI's
`Toaster` limits every toast transition to `transform` and `opacity`, puts it
on a spring, and lets heights change in one step.

## Replacing shadcn

`npx shadcn add @godui/sonner` overwrites `components/ui/sonner.tsx`. Exports
and props match shadcn/ui new-york-v4 (`Toaster`, with the same icons, theme
handling and CSS variables), so existing imports keep working. Keep calling
`toast()` from `sonner`.

If you pass `toastOptions.classNames`, GodUI merges its own classes with yours
rather than replacing them.

```tsx
import { Toaster } from "@/components/ui/sonner";
```


## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Enter, exit, stack | sonner's transitions | `transform`, `opacity` | `ease-spring-snappy` | 400ms |
| Stack expand (heights) | snaps | — | — | — |
| Swipe to dismiss | pointer-driven `transform` | `transform` | — | live |
| Action, cancel, close buttons | sonner's transition | `opacity` | — | sonner's |

Sonner injects its stylesheet unlayered, so GodUI's overrides use
`!important`; only `transition-property` and the easing are forced. Sonner's
own reduced-motion styles still apply.

## API

Built on [Sonner](https://sonner.emilkowal.ski/toaster). Props are identical to
[shadcn/ui Sonner](https://ui.shadcn.com/docs/components/sonner).
