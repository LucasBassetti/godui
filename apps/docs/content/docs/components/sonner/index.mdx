## API

### Toaster

Built on the [Sonner `Toaster`](https://sonner.emilkowal.ski/toaster); accepts all its props. Render it once, near the root of the app.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `"top-left" \| "top-center" \| "top-right" \| "bottom-left" \| "bottom-center" \| "bottom-right"` | `"bottom-right"` | Where the stack sits on screen. |
| `theme` | `"light" \| "dark" \| "system"` | `useTheme().theme` | Color scheme. Defaults to the current next-themes theme (`"system"` when unset). |
| `richColors` | `boolean` | `false` | Color success, info, warning and error toasts. |
| `expand` | `boolean` | `false` | Show every visible toast expanded instead of stacked. |
| `closeButton` | `boolean` | `false` | Add a close button to each toast. |
| `duration` | `number` | `4000` | Milliseconds before a toast dismisses itself. |
| `visibleToasts` | `number` | `3` | Number of toasts visible at once. |
| `gap` | `number` | `14` | Pixels between toasts when expanded. |
| `offset` | `string \| number \| { top?, right?, bottom?, left? }` | `"24px"` | Distance from the viewport edges. |
| `hotkey` | `string[]` | `["altKey", "KeyT"]` | Keys that focus the toast region. |
| `toastOptions` | `ToastOptions` | none | Defaults for every toast. `classNames` are merged with GodUI's, not replaced. |
| `icons` | `ToastIcons` | Lucide icons | Icons per toast type. Passing `icons` replaces the whole set. |

### toast

Imported from `sonner`, not from `@/components/ui/sonner`. `toast(message, options?)` shows a toast and returns its id. Variants: `toast.success`, `toast.info`, `toast.warning`, `toast.error`, `toast.loading`, `toast.promise`, `toast.custom`; `toast.dismiss(id?)` closes one or all. See the [Sonner toast docs](https://sonner.emilkowal.ski/toast).
