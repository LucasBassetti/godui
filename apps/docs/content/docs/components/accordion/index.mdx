The shadcn/ui accordion without height animation. A panel's height changes
in one step, and the items below it slide from where they were to where they
now are (FLIP), so the motion reads the same while only `translate` and
`opacity` animate. Opening panels slide in; closing panels fade out first,
then collapse.

## Replacing shadcn

`npx shadcn add @godui/accordion` overwrites `components/ui/accordion.tsx`.
Exports, props and `data-slot` attributes match shadcn/ui new-york-v4, so
existing imports keep working. It also installs `godui-motion`, which
includes the `useFlipGroup` hook the accordion uses.

You can delete shadcn's `accordion-down` / `accordion-up` keyframes from your
CSS; GodUI doesn't use them.

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
```

```tsx
<Accordion type="single" collapsible>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Open | height snaps; panel `godui-slide-in-from-top`; items below FLIP | `opacity`, `translate` | `ease-spring-snappy`; FLIP `ease-out-expo` | 260ms |
| Close | panel `godui-fade-out`, then height snaps; items below FLIP | `opacity`, `translate` | `ease-out-expo` | 150ms + 260ms |
| Chevron | `transition` on `transform` | `rotate(180deg)` | `ease-spring-snappy` | 260ms |

The FLIP covers the accordion's own items. Content after the accordion moves
with the height change in one step.

Under `prefers-reduced-motion` the items below jump to their new position, the
panel fades for 150ms, and the chevron turns instantly.
