## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@/components/ui/accordion";
```

```tsx
<Accordion type="single" collapsible>
  <AccordionItem value="item-1">
    <AccordionTrigger>Is it accessible?</AccordionTrigger>
    <AccordionContent>
      Yes. It adheres to the WAI-ARIA design pattern.
    </AccordionContent>
  </AccordionItem>
</Accordion>
```

## API

### Accordion

Built on [Radix Accordion Root](https://www.radix-ui.com/primitives/docs/components/accordion#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `"single" \| "multiple"` | none | Required. `single` opens one item at a time; `multiple` opens any number. |
| `value` | `string \| string[]` | none | Controlled open item. A `string` for `single`, a `string[]` for `multiple`. |
| `defaultValue` | `string \| string[]` | none | Open item on first render, when uncontrolled. |
| `onValueChange` | `(value: string \| string[]) => void` | none | Called when the open item changes. The value has the same shape as `value`. |
| `collapsible` | `boolean` | `false` | With `type="single"`, lets the open item be closed again. |
| `disabled` | `boolean` | `false` | Disables every item. |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | Arrow-key direction for moving between triggers. |
| `dir` | `"ltr" \| "rtl"` | none | Reading direction. Inherits from `DirectionProvider` when unset. |

### AccordionItem

Built on [Radix Accordion Item](https://www.radix-ui.com/primitives/docs/components/accordion#item); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Required. Unique id of the item within its accordion. |
| `disabled` | `boolean` | `false` | Disables this item. |

### AccordionTrigger

Built on [Radix Accordion Trigger](https://www.radix-ui.com/primitives/docs/components/accordion#trigger), wrapped in an Accordion Header (`<h3>`); accepts all its props. Renders a chevron after its children that turns when the item opens.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### AccordionContent

Built on [Radix Accordion Content](https://www.radix-ui.com/primitives/docs/components/accordion#content); accepts all its props. `className` applies to the inner wrapper around `children`, as in shadcn/ui.

Props match [shadcn/ui Accordion](https://ui.shadcn.com/docs/components/accordion).
