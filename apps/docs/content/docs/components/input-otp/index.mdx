The shadcn/ui one-time password input, built on
[input-otp](https://input-otp.rodz.dev). Each digit you type rises a few
pixels into its slot and fades in, and the fake caret blinks with `opacity`
only. The active slot's ring changes instantly.

## Replacing shadcn

`npx shadcn add @godui/input-otp` overwrites `components/ui/input-otp.tsx`.
Exports, props and `data-slot` attributes match shadcn/ui new-york-v4, so
existing imports keep working. It adds a `godui-caret-blink` keyframe to your
CSS; shadcn's `caret-blink` keyframe is no longer used.

## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@/components/ui/input-otp";
```

```tsx
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Type a digit | `godui-slide-in-from-bottom` | `translate` 0.5rem → 0, `opacity` | `ease-spring-snappy` | 260ms |
| Caret | `godui-caret-blink` | `opacity` | `ease-out`, infinite | 1.25s |
| Active slot ring | snaps | none | none | none |

Under `prefers-reduced-motion` digits fade in without rising. The caret still
blinks, as a native text caret does.

## API

Built on [input-otp](https://github.com/guilhermerodz/input-otp). Props are
identical to [shadcn/ui Input OTP](https://ui.shadcn.com/docs/components/input-otp).
