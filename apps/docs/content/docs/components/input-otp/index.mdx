## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@/components/ui/input-otp";
```

```tsx
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## API

### InputOTP

Built on [input-otp](https://github.com/guilhermerodz/input-otp)'s `OTPInput`, which renders one hidden `<input>` behind the slots; accepts all its props, including native input props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `maxLength` | `number` | none | Number of characters. Required. |
| `value` | `string` | none | Controlled value. |
| `onChange` | `(newValue: string) => unknown` | none | Called with the new value on every change. |
| `onComplete` | `(...args: any[]) => unknown` | none | Called once all `maxLength` characters are filled. |
| `pattern` | `string` | none | Regex source each character must match. `input-otp` exports `REGEXP_ONLY_DIGITS`, `REGEXP_ONLY_CHARS` and `REGEXP_ONLY_DIGITS_AND_CHARS`. |
| `inputMode` | `"none" \| "text" \| "tel" \| "url" \| "email" \| "numeric" \| "decimal" \| "search"` | `"numeric"` | Virtual keyboard to show on touch devices. |
| `pasteTransformer` | `(pasted: string) => string` | none | Rewrites pasted text before it is validated. |
| `disabled` | `boolean` | none | Disables the input and dims the slots. |
| `containerClassName` | `string` | none | Class for the wrapper `<div>` around the slots. `className` goes on the hidden input. |
| `textAlign` | `"left" \| "center" \| "right"` | `"left"` | Where the hidden input's own caret and selection sit. |
| `pushPasswordManagerStrategy` | `"increase-width" \| "none"` | `"increase-width"` | Widens the input so password manager badges don't cover the last slot. |

### InputOTPGroup

Renders a native `<div>` and accepts all of its props. Groups adjacent slots into one bordered row.

### InputOTPSlot

Renders a native `<div>` and accepts all of its props. Shows the character, the fake caret and the active ring for one position.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `index` | `number` | none | Position of the slot, starting at 0. Required. |

### InputOTPSeparator

Renders a `<div role="separator">` with a minus icon and accepts all of its props.

Props match [shadcn/ui Input OTP](https://ui.shadcn.com/docs/components/input-otp).
