## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";
```

```tsx
<Tabs defaultValue="account" className="w-[400px]">
  <TabsList>
    <TabsTrigger value="account">Account</TabsTrigger>
    <TabsTrigger value="password">Password</TabsTrigger>
  </TabsList>
  <TabsContent value="account">Make changes to your account here.</TabsContent>
  <TabsContent value="password">Change your password here.</TabsContent>
</Tabs>
```

## API

### Tabs

Built on [Radix Tabs Root](https://www.radix-ui.com/primitives/docs/components/tabs#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `defaultValue` | `string` | none | Tab selected initially when uncontrolled. |
| `value` | `string` | none | Controlled selected tab. Setting it from outside slides the indicator too. |
| `onValueChange` | `(value: string) => void` | none | Called when the selected tab changes. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout and arrow-key axis. |
| `activationMode` | `"automatic" \| "manual"` | `"automatic"` | `automatic` selects a tab on focus; `manual` waits for Enter or Space. |
| `dir` | `"ltr" \| "rtl"` | none | Reading direction for keyboard navigation. Inherits from a direction provider when unset. |

### TabsList

Built on [Radix Tabs List](https://www.radix-ui.com/primitives/docs/components/tabs#list); accepts all its props. Renders one extra element, an `aria-hidden` `<span data-slot="tabs-indicator">`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "line"` | `"default"` | `default` is a filled pill; `line` is an underline. |
| `loop` | `boolean` | `true` | Arrow keys wrap from the last tab to the first. |

### TabsTrigger

Built on [Radix Tabs Trigger](https://www.radix-ui.com/primitives/docs/components/tabs#trigger); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Required. Ties the trigger to its content. |
| `disabled` | `boolean` | `false` | Prevent selecting the tab. |
| `asChild` | `boolean` | `false` | Render the child element instead. |

### TabsContent

Built on [Radix Tabs Content](https://www.radix-ui.com/primitives/docs/components/tabs#content); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Required. Matches a trigger's `value`. |
| `forceMount` | `true` | none | Keep the panel mounted while inactive. |

### tabsListVariants

The `cva` function behind `TabsList`. Call `tabsListVariants({ variant })` to style another element as a tab list.
