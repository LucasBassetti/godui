## Usage

```tsx
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog";
```

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>
        This action cannot be undone. This will permanently delete your account
        and remove your data from our servers.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

## API

### Dialog

Built on [Radix Dialog Root](https://www.radix-ui.com/primitives/docs/components/dialog#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | none | Whether the dialog is open. Use when controlled. |
| `defaultOpen` | `boolean` | `false` | Whether the dialog starts open. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the dialog opens or closes. |
| `modal` | `boolean` | `true` | Make the rest of the page inert while open. |

### DialogTrigger

The button that opens the dialog. Built on [Radix Dialog Trigger](https://www.radix-ui.com/primitives/docs/components/dialog#trigger); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props. |

### DialogContent

The animated panel, portaled with its overlay. Built on [Radix Dialog Content](https://www.radix-ui.com/primitives/docs/components/dialog#content); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | `true` | Show the × button in the top-right corner. |
| `onOpenAutoFocus` | `(event: Event) => void` | none | Called when focus moves into the dialog on open. `event.preventDefault()` stops it. |
| `onCloseAutoFocus` | `(event: Event) => void` | none | Called when focus returns to the trigger on close. `event.preventDefault()` stops it. |
| `onEscapeKeyDown` | `(event: KeyboardEvent) => void` | none | Called on Escape. `event.preventDefault()` keeps the dialog open. |
| `onInteractOutside` | `(event: PointerDownOutsideEvent \| FocusOutsideEvent) => void` | none | Called on a pointer down or focus outside. `event.preventDefault()` keeps the dialog open. |
| `forceMount` | `true` | none | Keep the content mounted while closed. |

### DialogHeader

Renders a native `<div>` that stacks the title and description, and accepts all of its props.

### DialogFooter

Renders a native `<div>` for the actions and accepts all of its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `showCloseButton` | `boolean` | `false` | Append an outline "Close" button that closes the dialog. |

### DialogTitle, DialogDescription

Built on Radix [Title](https://www.radix-ui.com/primitives/docs/components/dialog#title) and [Description](https://www.radix-ui.com/primitives/docs/components/dialog#description); each accepts all its props. Radix announces both when the dialog opens.

### DialogClose

A button that closes the dialog. Built on [Radix Dialog Close](https://www.radix-ui.com/primitives/docs/components/dialog#close); accepts all its props, including `asChild`.

### DialogPortal, DialogOverlay

Built on Radix [Portal](https://www.radix-ui.com/primitives/docs/components/dialog#portal) and [Overlay](https://www.radix-ui.com/primitives/docs/components/dialog#overlay); each accepts all its props. `DialogContent` already renders both; the overlay fades in and out.

Props match [shadcn/ui Dialog](https://ui.shadcn.com/docs/components/dialog).
