
```tsx
<Skeleton className="h-[20px] w-[100px] rounded-full" />
```

## API

### Skeleton

Renders a native `<div>` and accepts all of its props. Size and shape it with `className` (`h-*`, `w-*`, `rounded-*`). The block is `relative overflow-hidden` so it can clip the band; a call site's `absolute` or `fixed` still wins.
