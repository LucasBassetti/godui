## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";
```

```tsx
<Textarea placeholder="Type your message here." />
```

## API

### Textarea

Renders a native `<textarea>` and accepts all of its props. It grows with its content (`field-sizing-content`).

Props match [shadcn/ui Textarea](https://ui.shadcn.com/docs/components/textarea).
