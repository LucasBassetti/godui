## Usage

```tsx
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@/components/ui/carousel";
```

```tsx
<Carousel>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

## API

### Carousel

Renders a native `<div>` (`role="region"`) and accepts all of its props. Sets up [Embla Carousel](https://www.embla-carousel.com/api/) and handles the left and right arrow keys.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `opts` | `EmblaOptionsType` | none | [Embla options](https://www.embla-carousel.com/api/options/) such as `align`, `loop` and `startIndex`. |
| `plugins` | `EmblaPluginType[]` | none | [Embla plugins](https://www.embla-carousel.com/plugins/), e.g. Autoplay. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Scroll axis. Sets Embla's `axis` to `x` or `y`. |
| `setApi` | `(api: CarouselApi) => void` | none | Receives the Embla API once it's ready, for `scrollTo`, `selectedScrollSnap` and events. |

### CarouselContent

Renders a native `<div>` and accepts all of its props. The viewport and the track Embla moves.

### CarouselItem

Renders a native `<div>` (`role="group"`) and accepts all of its props. One slide. Set its width with `basis-*` classes.

### CarouselPrevious, CarouselNext

Render a GodUI [Button](/docs/components/button) and accept all of its props. They scroll to the previous or next slide and are disabled at either end.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"outline"` | Button style. |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"icon"` | Button size. |

### CarouselApi

The type of the Embla API that `setApi` receives (`UseEmblaCarouselType[1]`).

Props match [shadcn/ui Carousel](https://ui.shadcn.com/docs/components/carousel).
