The shadcn/ui button with a tactile press: on `:active` it scales to 97% and
springs back on release. Only `scale` animates, so the press runs on the GPU
compositor. Colors and the focus ring change instantly.

## Replacing shadcn

`npx shadcn add @godui/button` overwrites `components/ui/button.tsx`. Exports,
props and `data-slot` attributes match shadcn/ui new-york-v4, so existing
imports keep working. It also installs `godui-motion` (easings, keyframes, the
FLIP hook) into your project.

## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button variant="outline">Button</Button>
```

## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Press | `transition` on `active:scale-[0.97]` | `scale` | `ease-spring-bouncy` | 260ms |
| Hover, focus | snaps | — | — | — |

shadcn's button uses `transition-all`, which also animates background color,
border and the focus ring's `box-shadow` — all repainted on the main thread.
GodUI animates only `scale`. The `link` variant doesn't scale.

Under `prefers-reduced-motion` the press scales instantly, with no spring.

## API

Built on [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot)
for `asChild`. Props are identical to
[shadcn/ui Button](https://ui.shadcn.com/docs/components/button).
