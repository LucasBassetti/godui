## API

### Switch

Built on [Radix Switch Root](https://www.radix-ui.com/primitives/docs/components/switch#root); accepts all its props. Renders a `<button role="switch">` with the thumb inside.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"default" \| "sm"` | `"default"` | Track and thumb size. |
| `checked` | `boolean` | none | Controlled checked state. |
| `defaultChecked` | `boolean` | none | Initial state when uncontrolled. |
| `onCheckedChange` | `(checked: boolean) => void` | none | Called when the state changes. |
| `disabled` | `boolean` | none | Prevent interaction. |
| `required` | `boolean` | none | Mark the field as required in a form. |
| `name` | `string` | none | Form field name. |
| `value` | `string` | `"on"` | Value submitted with the form when checked. |

To change the checked color, set it on the fade layer: `data-[state=checked]:before:bg-*`.
