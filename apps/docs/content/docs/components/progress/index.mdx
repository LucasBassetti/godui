## API

### Progress

Built on [Radix Progress Root](https://www.radix-ui.com/primitives/docs/components/progress#root); accepts all its props. Renders its own indicator.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| null` | none | Progress from 0 to 100. Leave it out or pass `null` for an indeterminate bar. |
| `max` | `number` | `100` | Maximum value, used for the ARIA attributes. The fill reads `value` as a percentage, so keep it at 100. |
| `getValueLabel` | `(value: number, max: number) => string` | none | Builds `aria-valuetext`. Without it Radix uses the rounded percentage. |

Props match [shadcn/ui Progress](https://ui.shadcn.com/docs/components/progress).
