## API

### Input

Renders a native `<input>` and accepts all of its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `string` | none | Native input type. `file` styles the picker button to match. |
| `disabled` | `boolean` | none | Dims the field and blocks pointer events. |
| `aria-invalid` | `boolean \| "true" \| "false" \| "grammar" \| "spelling"` | none | Switches the border and focus ring to the destructive color. |

Props match [shadcn/ui Input](https://ui.shadcn.com/docs/components/input).
