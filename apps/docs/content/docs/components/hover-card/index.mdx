## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card";
```

```tsx
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>
    The React Framework, created and maintained by @vercel.
  </HoverCardContent>
</HoverCard>
```

## API

### HoverCard

Built on [Radix Hover Card Root](https://www.radix-ui.com/primitives/docs/components/hover-card#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | none | Controlled open state. |
| `defaultOpen` | `boolean` | none | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the open state changes. |
| `openDelay` | `number` | `700` | Milliseconds from pointer enter until the card opens. |
| `closeDelay` | `number` | `300` | Milliseconds from pointer leave until the card closes. |

### HoverCardTrigger

Built on [Radix Hover Card Trigger](https://www.radix-ui.com/primitives/docs/components/hover-card#trigger); renders an `<a>` and accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### HoverCardContent

Built on [Radix Hover Card Content](https://www.radix-ui.com/primitives/docs/components/hover-card#content), rendered in a portal; accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side of the trigger. Flips when it would collide. |
| `sideOffset` | `number` | `4` | Distance from the trigger in px. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `alignOffset` | `number` | `0` | Offset from the `align` position in px. |
| `avoidCollisions` | `boolean` | `true` | Flip and shift to stay inside the collision boundary. |
| `collisionPadding` | `number \| Partial<Record<Side, number>>` | `0` | Distance from the boundary edges where collisions are detected. |
| `forceMount` | `true` | none | Keep the content mounted while closed. |

Props match [shadcn/ui Hover Card](https://ui.shadcn.com/docs/components/hover-card).
