The shadcn/ui hover card, with the same directional entrance as
[Popover](/docs/components/popover): it scales up from the edge touching the
link and drifts 4px away from it on a spring, then leaves the same way in
150ms. Only `scale`, `translate` and `opacity` animate.

## Replacing shadcn

`npx shadcn add @godui/hover-card` overwrites `components/ui/hover-card.tsx`.
Exports, props and `data-slot` attributes match shadcn/ui new-york-v4, so
existing imports keep working. It also installs `godui-motion` (easings,
keyframes, the FLIP hook) into your project.

## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card";
```

```tsx
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>
    The React Framework – created and maintained by @vercel.
  </HoverCardContent>
</HoverCard>
```

## What's animated

| Interaction | Keyframe / mechanism | Properties | Easing | Duration |
| --- | --- | --- | --- | --- |
| Open (after `openDelay`) | `godui-popover-in` | `opacity`, `scale` 0.96 → 1 from the link, `translate` 4px → 0 | `ease-spring-snappy` | 260ms |
| Close (after `closeDelay`) | `godui-popover-out` | the same, reversed | `ease-out-expo` | 150ms |

Under `prefers-reduced-motion` the card only fades (150ms).

Built on [Radix Hover Card](https://www.radix-ui.com/primitives/docs/components/hover-card).
Props are identical to [shadcn/ui Hover Card](https://ui.shadcn.com/docs/components/hover-card).
