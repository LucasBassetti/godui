## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";
```

```tsx
<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```

## API

### ToggleGroup

Built on [Radix Toggle Group Root](https://www.radix-ui.com/primitives/docs/components/toggle-group#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `"single" \| "multiple"` | none | Required. `single` allows one pressed item and slides an indicator to it. `multiple` allows any number. |
| `value` | `string` (single) \| `string[]` (multiple) | none | Controlled pressed value(s). |
| `defaultValue` | `string` (single) \| `string[]` (multiple) | none | Pressed value(s) on first render when uncontrolled. |
| `onValueChange` | `(value: string) => void` (single) \| `(value: string[]) => void` (multiple) | none | Called when the pressed value(s) change. |
| `variant` | `"default" \| "outline"` | none | Passed to every item. Items fall back to their own `variant`, then `"default"`. |
| `size` | `"default" \| "sm" \| "lg"` | none | Passed to every item. Items fall back to their own `size`, then `"default"`. |
| `spacing` | `number` | `0` | Gap between items, in Tailwind spacing units. `0` joins items into one segmented block. |
| `disabled` | `boolean` | `false` | Disables every item. |
| `orientation` | `"horizontal" \| "vertical"` | none | Arrow-key direction for roving focus. Both directions work when unset. |
| `rovingFocus` | `boolean` | `true` | Move focus between items with arrow keys. |
| `loop` | `boolean` | `true` | Wrap focus from the last item to the first. |
| `asChild` | `boolean` | `false` | Render the child element instead. Disables the sliding indicator. |

### ToggleGroupItem

Built on [Radix Toggle Group Item](https://www.radix-ui.com/primitives/docs/components/toggle-group#item); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Required. Unique value of the item within the group. |
| `variant` | `"default" \| "outline"` | `"default"` | Visual style. The group's `variant` wins when set. |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` | Height and padding. The group's `size` wins when set. |
| `disabled` | `boolean` | `false` | Disables this item. |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

Props match [shadcn/ui Toggle Group](https://ui.shadcn.com/docs/components/toggle-group).
