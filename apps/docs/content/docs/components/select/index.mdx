## Usage

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx
<Select>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="light">Light</SelectItem>
    <SelectItem value="dark">Dark</SelectItem>
    <SelectItem value="system">System</SelectItem>
  </SelectContent>
</Select>
```

## API

### Select

Built on [Radix Select Root](https://www.radix-ui.com/primitives/docs/components/select#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Controlled selected value. |
| `defaultValue` | `string` | none | Selected value on first render, when uncontrolled. |
| `onValueChange` | `(value: string) => void` | none | Called when the selection changes. |
| `open` | `boolean` | none | Controlled open state of the list. |
| `defaultOpen` | `boolean` | none | Open state on first render, when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | none | Called when the list opens or closes. |
| `disabled` | `boolean` | none | Disables the select. |
| `required` | `boolean` | none | A value must be selected before the form submits. |
| `name` | `string` | none | Name of the value submitted with a form. |

### SelectTrigger

Built on [Radix Select Trigger](https://www.radix-ui.com/primitives/docs/components/select#trigger); accepts all its props. Adds the chevron icon.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` | Trigger height: `h-8` or `h-9`. |

### SelectValue

Built on [Radix Select Value](https://www.radix-ui.com/primitives/docs/components/select#value); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placeholder` | `ReactNode` | none | Shown while no value is selected. |

### SelectContent

Built on [Radix Select Content](https://www.radix-ui.com/primitives/docs/components/select#content), rendered in a portal; accepts all its props. Wraps its children in the viewport between the scroll buttons.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `"item-aligned" \| "popper"` | `"item-aligned"` | `item-aligned` puts the selected item over the trigger. `popper` opens beside the trigger like a popover. |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side of the trigger. `popper` only. |
| `sideOffset` | `number` | `0` | Distance from the trigger in px. `popper` only; the content also adds a 4px offset of its own. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. `popper` only. |
| `onCloseAutoFocus` | `(event: Event) => void` | none | Called when focus returns to the trigger on close. |
| `onEscapeKeyDown` | `(event: KeyboardEvent) => void` | none | Called when Escape is pressed. Prevent it to keep the list open. |

### SelectGroup, SelectLabel

Built on [Radix Select Group](https://www.radix-ui.com/primitives/docs/components/select#group) and [Label](https://www.radix-ui.com/primitives/docs/components/select#label); accept all their props. A label inside a group names it.

### SelectItem

Built on [Radix Select Item](https://www.radix-ui.com/primitives/docs/components/select#item); accepts all its props. Adds the check indicator.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | none | Required. The value this item selects. Can't be an empty string. |
| `disabled` | `boolean` | none | Disables this item. |
| `textValue` | `string` | none | Text used for typeahead when the item's content isn't plain text. |

### SelectSeparator

Built on [Radix Select Separator](https://www.radix-ui.com/primitives/docs/components/select#separator); accepts all its props.

### SelectScrollUpButton, SelectScrollDownButton

Built on [Radix Select ScrollUpButton](https://www.radix-ui.com/primitives/docs/components/select#scrollupbutton) and [ScrollDownButton](https://www.radix-ui.com/primitives/docs/components/select#scrolldownbutton); accept all their props. `SelectContent` already renders both.

Props match [shadcn/ui Select](https://ui.shadcn.com/docs/components/select).
