## API

### Toggle

Built on [Radix Toggle](https://www.radix-ui.com/primitives/docs/components/toggle#root); accepts all its props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "outline"` | `"default"` | Visual style. `outline` adds a border and shadow. |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` | Height and padding. |
| `pressed` | `boolean` | none | Controlled pressed state. |
| `defaultPressed` | `boolean` | `false` | Pressed state on first render when uncontrolled. |
| `onPressedChange` | `(pressed: boolean) => void` | none | Called when the pressed state changes. |
| `disabled` | `boolean` | `false` | Prevents interaction. |
| `asChild` | `boolean` | `false` | Render the child element instead, merging props via [Radix Slot](https://www.radix-ui.com/primitives/docs/utilities/slot). |

### toggleVariants

The `cva` function behind `Toggle`. Call `toggleVariants({ variant, size })` to style another element as a toggle. Toggle Group uses it for its items.
